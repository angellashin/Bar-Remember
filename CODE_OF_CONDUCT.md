# Code of Conduct

BarRemember is a small open-source project and welcomes contributors of all backgrounds.

Be respectful, specific, and constructive. Harassment, discrimination, personal attacks, doxxing, sexualized language, and intentionally disruptive behavior are not acceptable in issues, pull requests, discussions, or other project spaces.

If you experience or observe a problem, contact the repository maintainer privately through the GitHub profile rather than posting personal information publicly. The maintainer may edit, hide, or close content that does not meet these standards.
