# BarRemember

BarRemember는 Apple Reminders의 미완료 항목을 사용자가 만든 공간별로 나눠 macOS 메뉴 막대에서 확인하고 관리하는 가벼운 네이티브 앱입니다.

## 기능

- Reminders 전체 접근 권한을 macOS 시스템 대화상자로 요청
- 큰 직접 선택 탭으로 `할 일`, `공부`, `장보기`, `지원 공고` 등 원하는 공간을 한 번에 전환
- 공간이 많아지면 탭 영역만 가로 스크롤하고 현재 공간을 자동으로 가운데 표시
- 오른쪽 `+`로 임의 이름의 공간을 추가하고 설정에서 이름 변경·삭제
- 각 Reminders 목록을 `숨김` 또는 사용자 공간 한 곳에만 연결
- 공간 이름과 같은 Reminders 목록을 앱에서 바로 생성하거나 기존 목록을 연결
- 기존에 선택해 둔 목록과 사용 중인 `지원 공고` 목록은 업데이트 후에도 그대로 유지
- 선택한 공간의 미완료 항목을 마감일 → 우선순위 → 제목 순으로 표시
- 각 행 오른쪽 손잡이를 드래그해 BarRemember 안의 순서를 직접 변경하고 Mac에 유지
- 제목을 더블클릭하거나 연필 버튼을 눌러 행 안에서 제목과 마감 날짜를 함께 추가·변경·삭제하고 Apple Reminders에 저장
- 항목 카드 아래에는 내부 Reminders 목록 이름을 표시하지 않고, 지정된 마감 날짜만 표시
- 메뉴 막대의 완료 원을 눌러 즉시 완료 처리하고 목록에서 제거
- 완료 직후 8초 동안 표시되는 메시지에서 최근 완료 1건 되돌리기
- 선택한 공간에 새 항목을 추가하면서 선택적으로 마감 날짜 지정
- `CJ 지원서 마감 9/28`, `자료 보내기 내일`처럼 제목 끝에 날짜를 쓰면 자동으로 감지해 마감일로 저장하고 날짜 문구는 제목에서 제거
- 자동 감지된 날짜 행을 누르면 기존 날짜 선택기로 전환되어 저장 전에 직접 수정 가능
- 새 항목과 기존 항목의 날짜 편집은 동일한 macOS 시스템 DatePicker와 SF Symbols 사용
- 완료 원 색상을 6가지 프리셋에서 선택
- 전체 화면 테마를 `시스템`, `Glass`(반투명 블루 글래스), `미드나이트`(투명 네이비 글래스), `페이퍼`에서 선택
- 하단 `종료…`를 누른 뒤 `앱 종료`를 명시적으로 확인해야만 앱 종료
- Reminders 변경 시 자동 갱신
- 로그인 시 자동 실행 옵션
- Dock 아이콘 없이 메뉴 막대에서만 실행

## 개인정보 보호

리마인더 데이터는 Apple EventKit을 통해 Mac의 Reminders 데이터베이스에서 직접 읽고 씁니다. 공간 이름과 목록 연결 정보는 이 Mac의 BarRemember 설정에 저장되며 별도 서버, 분석 도구 또는 외부 계정은 사용하지 않습니다.

공간을 삭제해도 Apple Reminders의 목록과 항목은 삭제되지 않고 BarRemember의 연결만 해제됩니다.

드래그로 정한 순서는 Apple Reminders의 항목 내용을 바꾸지 않고 이 Mac의 BarRemember 설정에만 저장됩니다. EventKit 공개 API가 Apple Reminders의 임의 수동 순서를 제공하지 않기 때문입니다.

## BarRemember가 집중하는 것

BarRemember는 Apple Reminders의 모든 기능을 메뉴 막대에 옮기려 하지 않습니다. 자주 보는 목록만 원하는 이름의 공간으로 묶고, 한 번의 클릭으로 전환해 제목·마감일·완료 상태를 관리하는 데 집중합니다. 날짜는 한국어와 영어의 명확한 제목 끝 표현을 규칙으로 감지하며, AI나 별도 서버를 사용하지 않습니다.

## 빌드

```sh
chmod +x Scripts/build-app.sh
Scripts/build-app.sh
```

완성된 앱은 `dist/BarRemember.app`에 생성됩니다. 처음 실행하면 메뉴 막대의 체크리스트 아이콘을 누르고 `리마인더 연결`을 선택하세요.

## 권한을 다시 설정해야 할 때

시스템 설정 → 개인정보 보호 및 보안 → 리마인더에서 BarRemember 접근을 변경할 수 있습니다.
